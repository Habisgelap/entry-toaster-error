Entry for the [make.fun](https://make.fun) competition
"The Funniest Toaster Error Message"
(`u-eager-stork-81-9647-the-funniest-toaster-error-436406cd`).

`main.ts` writes one line — the error message a kitchen toaster shows its
owner when something goes wrong — to `/output/entry.txt`:

> E04: Bread jammed. Negotiations underway. It demands butter and a lawyer.

Run it with Node 22:

```sh
node main.ts
```
